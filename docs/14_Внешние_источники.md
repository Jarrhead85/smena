# Внешние источники и актуальные ограничения

Дата проверки: 10 ноября 2026. При изменении API или целевой платформы сверить первоисточник повторно. Не заменять официальную документацию фрагментами из блогов.

## GigaChat

1. [Работа с файлами](https://developers.sber.ru/docs/ru/gigachat/guides/working-with-files) — `POST /files`, `purpose="general"`, удаление через `POST /files/{file}/delete`, максимум изображения 15 МБ, одно изображение в сообщении, attachments.
2. [Сгенерировать ответ](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/post-chat) — chat completions и передача изображений через attachments.
3. [Получить токен доступа](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/post-token) — Authorization Key, access token со сроком 30 минут.
4. [Авторизация GigaChat API](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api) — OAuth URL, RqUID, scope, текущий API base URL.
5. [Использование SDK](https://developers.sber.ru/docs/ru/gigachat/guides/using-sdks) — поддерживаемые официальные SDK и требования сертификатов. Официальный C# SDK здесь не заявлен, поэтому проект использует REST.

## Android

1. [Schedule alarms](https://developer.android.com/develop/background-work/services/alarms) — exact alarms, `SCHEDULE_EXACT_ALARM`, `canScheduleExactAlarms()`, resync после выдачи доступа.
2. [Android 14: exact alarms denied by default](https://developer.android.com/about/versions/14/changes/schedule-exact-alarms) — необходимость явно обрабатывать отказ.
3. [Android 13 features](https://developer.android.com/about/versions/13/features) — ограничения `USE_EXACT_ALARM`; не выбирать его автоматически.
4. [Notifications overview](https://developer.android.com/develop/ui/views/notifications) — каналы, действия и системное поведение.

## .NET MAUI

1. [Local notifications](https://learn.microsoft.com/en-us/dotnet/maui/platform-integration/local-notifications?view=net-maui-10.0) — нативная реализация, AlarmManager/BroadcastReceiver, `POST_NOTIFICATIONS`.
2. [.NET MAUI для .NET 10](https://learn.microsoft.com/en-us/dotnet/maui/whats-new/dotnet-10?view=net-maui-10.0) — `net10.0-android`, MediaPicker, рекомендации по Android API.
3. [Supported platforms](https://learn.microsoft.com/en-us/dotnet/maui/supported-platforms?view=net-maui-10.0) — поддерживаемые платформы.
4. [.NET support policy](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core) — .NET 10 LTS и срок поддержки.
5. [Secure Storage](https://learn.microsoft.com/en-us/dotnet/maui/platform-integration/storage/secure-storage?view=net-maui-10.0) — защищённое хранение небольших секретных значений.

## Kimi Code

1. [Agents and Sub-Agents](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/agents.html) — формат custom agents, `.kimi-code/agents/`, frontmatter и tool boundaries.
2. [Agent Skills](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/skills.html) — формат `SKILL.md`, `.kimi-code/skills/`, автоматическое и ручное использование.

## Правило

Параметры API, модели, разрешения и поведение ОС могут меняться. Перед релизом инженер обязан проверить официальные страницы и зафиксировать фактические версии. Если источник противоречит проектному документу, создать задачу на обновление документации и не продолжать на устаревшем предположении молча.
