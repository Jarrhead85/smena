# Промпт: напоминания

Используй `maui-android-implementation` и `shift-release-verification`. Прочитай `docs/08_Напоминания_и_офлайн.md`, модель данных и безопасность.

Сначала реализуй и проверь минимальный нативный notification spike на устройстве/эмуляторе. Затем интегрируй его через `IReminderScheduler`:

- Advance и Due, lead=0 и прошедшие времена;
- стабильные request codes, Immutable explicit PendingIntent без PII;
- отмена при edit/delete/status/complete shift;
- notification channel, deep link и идемпотентное Done;
- POST_NOTIFICATIONS и SCHEDULE_EXACT_ALARM с честным denied UX;
- boot, time/timezone, permission state и package replaced resync;
- private lock-screen public version;
- никаких сетевых запросов из receiver.

Не считай задачу готовой только по unit-тестам. Выполни и задокументируй device-сценарии: оба события, reboot, denied/revoked permission, Doze, холодный запуск по уведомлению. Если устройство недоступно, оставь release gate открытым и не утверждай о надёжности.
