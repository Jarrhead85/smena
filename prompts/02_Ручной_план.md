# Промпт: ручной вертикальный срез

Используй навыки `nurse-shift-domain` и `maui-android-implementation`. Прочитай функциональное ТЗ, UX, UI kit, архитектуру, модель данных и стандарты кода.

Реализуй рабочий ручной план без GigaChat:

- создание одной активной смены, включая ночную;
- SQLCipher persistence и миграция;
- ручное добавление/редактирование/удаление назначения;
- лента с временными группами и прогрессом;
- Pending/Done/Skipped и Overdue без автопропуска;
- завершение смены и read-only история;
- светлая/тёмная тема, русские ресурсы, empty/error states;
- базовая доступность по UI kit.

Не добавляй видимые кнопки импорта, если они ещё не работают. Напоминания на этом шаге не имитируй. Сначала покажи атомарный план с тестами, затем реализуй небольшими частями. Запусти unit/integration тесты и Android build. Для UI проверь 360 dp, 200% font и TalkBack насколько позволяет окружение; невыполненные device-проверки укажи явно.
