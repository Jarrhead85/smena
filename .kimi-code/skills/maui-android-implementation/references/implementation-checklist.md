# Implementation checklist

## Перед кодом

- Прочитаны FR, архитектура и функциональный документ.
- Есть узкий критерий и тест.
- Проверены существующие интерфейсы и зависимости.
- Нет необходимости в preview package или новой телеметрии.

## Core/Infrastructure

- Core независим от платформы; часы и cancellation внедрены.
- DTO отделены; внешние ошибки sanitised.
- Миграция/транзакция/индекс добавлены при необходимости.
- Повторная операция идемпотентна.
- БД/фото/секреты защищены и не логируются.

## Android

- Разрешение проверено до операции и после возврата.
- Explicit immutable PendingIntent, стабильный request code, extras только ID.
- Receiver проверяет актуальное состояние БД.
- Boot/time/timezone/permission/package replaced resync применимы.
- Device test выполнен или gate оставлен открытым.

## UI

- Семантические токены, русские ресурсы, нет hardcoded повторных цветов.
- Все состояния и действия работают; back не теряет ввод молча.
- 48 dp, TalkBack, 200% font, dark theme, long text, reduced motion.
- Нет dead controls, binding errors и непроверенных обещаний.

## Отчёт

- Файлы и поведение.
- Команды/сценарии и фактический результат.
- Непроверенное и риски.
- Обновлённые docs/ADR.
