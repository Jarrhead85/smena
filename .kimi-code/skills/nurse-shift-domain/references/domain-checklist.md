# Domain checklist

## Смена

- Одна Active; 0 < длительность ≤24 часов; ночная дата корректна.
- Пояс и DueLocal сохранены; UTC вычислено; неоднозначность не угадывается.
- Complete отменяет будущие alarms и оставляет read-only историю.

## Назначение

- Confirm требует пациента, процедуру и допустимое время.
- Дополнительные поля могут быть пустыми; длины ограничены.
- Дубли и одинаковые ФИО только помечаются.
- Done/Skipped требуют времени изменения; Overdue вычисляется.
- Edit Done/Skipped с подтверждением возвращает Pending.
- Delete/Complete/Done/Skipped отменяют будущие alarms.

## Импорт

- Preparing/Processing/Review не создают подтверждённый план.
- Неразобранные строки явно перенесены или исключены.
- Confirm атомарен и идемпотентен.
- Ошибка scheduling видна и не откатывает план.
- Черновик переживает process death; источник остаётся доступен до завершения.

## Общее

- Offline; no PII logs; no clinical inference; только синтетические fixtures.
- Новое поведение имеет FR и тест.
